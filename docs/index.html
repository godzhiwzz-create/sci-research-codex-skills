01 / THE RESEARCH LOOP

接住研究目标，
推进下一步
有依据的行动。

核心是研究判断与项目推进。根据已有证据选择进入点；有了新结果，就重新比较解释与下一步，不必每次从头走一遍流程。

用户决定目标、重大取舍与授权。研究负责人承担假设比较、证据整合和下一步选择；需要你决定时，带着理由和建议回来。

阅读项目接续与决策说明 ↗
1

接续课题 CONTEXT

从已有项目找回研究目标、当前假设、已核验证据和卡点，弄清眼前真正需要回答的问题。

2

比较路线 HYPOTHESES

结合最近先例与已有结果，比较可行路线、重合之处和待验证差别，给出有理由的研究选择。

3

设计与推进实验 EXPERIMENTS

写清实验要改变哪项判断，固定协议和对照。在已有授权内推进执行、跟踪运行，保留原始结果。

4

根据结果决定下一步 DECISIONS

核对原始证据，区分有效信号、负结果与工程故障。决定继续、复用、转向或停止，而非机械追加实验。

5

接续状态，推进论文 CONTINUITY

更新发生变化的项目状态，把可用证据交给写作与修订流程。下次从当前问题和下一动作继续。

以研究目标为中心在授权范围内自主推进用原始证据核验判断重要取舍由你决定

02 / SUPPORTING SKILLS

一个研究主线，
按需调用不同能力。

研究负责人整合判断，写作入口维护稿件主线；检索、精读、实验记录和核验提供必要支持。窄任务也可以直接使用对应模块。

01研究判断 / 项目推进↗

“围绕这个目标，
把研究接着推进。”

整合文献与实验，比较假设、推进已授权的工作，并根据证据调整下一动作，维护一条连续的研究主线。

核心职责：研究决策、证据与项目接续sci-research-manager
02论文写作 / 审稿修订↗

“结果有了，
怎样讲成一篇论文？”

从已有证据出发组织主线，起草和打磨稿件，处理审稿意见。按当前阶段工作，保留结论的适用边界。

你会得到：稿件、修订稿或逐条回复academic-manuscript-writing
03文献来源↗

“有没有人做过类似的？”

按问题寻找来源，核对身份与重复文献。也能只处理你给出的一篇论文。

得到：来源清单、核验状态与引用信息sci-literature-manager
04论文阅读↗

“这篇方法到底怎么工作？”

拆解问题、机制和关键实验；具体疑点读相关原文，完整精读再组织图文理解包。

得到：方法解释、图表解读与原文定位sci-paper-reader
05实验记录↗

“这次实验究竟回答什么？”

把假设、对照和成功标准写清楚，将运行记录与原始结果连接起来，保留失败和负结果。

得到：实验卡、固定协议与结果入口sci-experiment-manager
06证据核验↗

“这个结论，证据够吗？”

沿原始结果核对数字、协议与论文表述，找出不一致和缺失依据，不替你补造结果。

得到：证据对应、冲突项与结论边界sci-result-auditor
07论文配套↗

“投稿材料还缺什么？”

整理主张与证据的对应关系、图表计划和文件清单，明确哪些材料仍待准备。

得到：图表计划、证据映射与材料清单sci-paper-manager
08资产维护↗

“这些文件，还能放心整理吗？”

检查代码、数据和结果的依赖与留存价值。先给归档或迁移建议，再由你决定是否操作。

得到：资产清单、依赖风险与整理建议sci-asset-manager

04 / START FROM YOUR PROJECT

给出目标与边界，
从现有课题开始。

先安装研究主入口，再提供项目目录、研究目标与授权范围。其他模块按任务需要使用，不必重建资料库。

  • 使用 Codex 与 Python 3.10+
  • 沿用已有项目与规则
  • 安装后重新加载 Skill 列表
“用 $sci-research-manager 接续这个项目。根据当前研究目标和已有证据，比较可行路线，在已有授权内推进下一步，并根据结果更新判断。超出授权时带着具体方案找我。”

如果只想讨论，直接注明“本次只讨论，不启动实验”。持续执行与等待还需要可用的运行环境和相应授权；安装 Skill 本身不会启动后台任务。

安装说明与更多提问示例 ↗
TERMINAL先预览 · 再安装
01 / 克隆仓库并预览
git clone https://github.com/godzhiwzz-create/sci-research-codex-skills.git
cd sci-research-codex-skills
python3 scripts/install_skills.py --skill sci-research-manager
02 / 确认预览后，手动执行
python3 scripts/install_skills.py --skill sci-research-manager --apply

复制不会执行命令。只有 --apply 才写入安装目录。

它帮助你组织研究，不保证创新、实验成功或论文录用。关键结论仍需核对原始证据；远端执行和对外提交遵守你的授权。
