01 / WHAT YOU NEED

你卡在哪一步？
从这里开始。

想读懂一篇论文，还是接续一个长期课题？选与你眼前问题对应的入口即可，不需要先搭建一套庞大的系统。

01方向讨论 / 项目接续↗

“这个想法，
还值得往下做吗？”

把你的问题、已有文献和实验放在一起，比较最近先例与竞争解释，给出有理由的下一步建议。

你会得到：先例比较、证据缺口与下一步sci-research-manager
02论文写作 / 审稿修订↗

“结果有了，
怎样讲成一篇论文？”

从已有证据出发组织主线，起草和打磨稿件，处理审稿意见。按当前阶段工作，保留结论的适用边界。

你会得到：稿件、修订稿或逐条回复academic-manuscript-writing
03文献来源↗

“有没有人做过类似的？”

按问题寻找来源，核对身份与重复文献。也能只处理你给出的一篇论文。

得到：来源清单、核验状态与引用信息sci-literature-manager
04论文阅读↗

“这篇方法到底怎么工作？”

拆解问题、机制和关键实验；具体疑点读相关原文，完整精读再组织图文理解包。

得到：方法解释、图表解读与原文定位sci-paper-reader
05实验记录↗

“这次实验究竟回答什么？”

把假设、对照和成功标准写清楚，将运行记录与原始结果连接起来，保留失败和负结果。

得到：实验卡、固定协议与结果入口sci-experiment-manager
06证据核验↗

“这个结论，证据够吗？”

沿原始结果核对数字、协议与论文表述，找出不一致和缺失依据，不替你补造结果。

得到：证据对应、冲突项与结论边界sci-result-auditor
07论文配套↗

“投稿材料还缺什么？”

整理主张与证据的对应关系、图表计划和文件清单，明确哪些材料仍待准备。

得到：图表计划、证据映射与材料清单sci-paper-manager
08资产维护↗

“这些文件，还能放心整理吗？”

检查代码、数据和结果的依赖与留存价值。先给归档或迁移建议，再由你决定是否操作。

得到：资产清单、依赖风险与整理建议sci-asset-manager
8 个入口按需使用，不是 8 个常驻代理。已有项目规则、目录和证据始终优先。了解模块如何配合 ↗

从一次提问，
到一个
长期课题。

你决定目标和投入范围。小问题直接回答；需要深入时，再衔接文献、实验和写作。右侧是不同使用方式，不是必经步骤。

看看如何接续一个项目 ↗
◇

讨论一个想法 DISCUSS

回答眼前的问题，指出可检验差别。不自动建档、下载或远端执行。

⌕

做一次定向查新 VERIFY PRIOR ART

核验最近先例，说明实质重合与尚未测试的差别，不轻率否定整个方向。

⊙

进行最小探索 PROBE

在已有授权内，用小而固定的协议区分竞争解释，为下一次决定提供信息。

⊞

开展正式实验 EXPERIMENT

保留完整协议、公平对照、统计标准与原始证据，完成实验记录闭环。

✓

准备投稿审计 AUDIT

对冻结材料做完整一致性检查。发现缺口就明确报告，不自动提交。

沿用已有资料结果可以追溯结论保留边界重要取舍由你决定

04 / START WITH ONE QUESTION

带上你的问题，
在 Codex 中开始。

先选一个需要的 Skill，预览安装计划，确认后安装。然后提供论文、项目目录或已有结果，就能从眼前的问题开始。

  • 使用 Codex 与 Python 3.10+
  • 无需搬迁已有项目或资料库
  • 安装后重新加载 Skill 列表
“用 $sci-research-manager 接续这个项目，找出当前问题、已有证据和最值得做的下一步。先讨论，不启动实验。”
安装说明与更多提问示例 ↗
TERMINAL先预览 · 再安装
01 / 克隆仓库并预览
git clone https://github.com/godzhiwzz-create/sci-research-codex-skills.git
cd sci-research-codex-skills
python3 scripts/install_skills.py --skill sci-research-manager
02 / 确认预览后，手动执行
python3 scripts/install_skills.py --skill sci-research-manager --apply

复制不会执行命令。只有 --apply 才写入安装目录。

它帮助你组织研究，不保证创新、实验成功或论文录用。关键结论仍需核对原始证据；远端执行和对外提交遵守你的授权。
