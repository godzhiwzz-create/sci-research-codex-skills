SCI Research Codex Skills · 8 个通用科研 Skill

让科研进展有迹可循

从一个论文问题到一个长期项目，按需处理文献、实验、证据与写作。结论有出处，实验有协议；一次讨论，不必开启整套执行流程。

安装与快速开始 按任务选择 Skill 中文教程 GitHub 仓库

稳定版 v2.0.0 · 按需工作流等最新能力在 main，尚未形成新 Release。

从当前问题开始

不必同时调用全部 Skill。选一个与任务匹配的入口，只在需要时交接；项目自己的规则、目录和事实来源始终优先。

研究状态

接续项目，讨论下一步

恢复当前问题、证据和缺口。判断是否值得投入时先核验最近先例，不把讨论自动变成实验。

sci-research-manager
文献来源

查新，或给已知论文入库

验证题录、版本与来源。已知论文查重后增量登记；检索只围绕尚未解决的问题扩展。

sci-literature-manager
论文阅读

读懂机制，核对证据

小问题读取决定性原文并标注位置；需要完整精读时，再生成可复用的理解包与图表说明。

sci-paper-reader
实验记录

把已批准的实验闭环

固定协议、原始结果、卡片与索引。通过 SSH 连接用户配置的服务器，一个任务一个监控负责人。

sci-experiment-manager
证据核验

结果与论文主张对得上吗

发现冲突就回到原始结果和固定协议，明确证据范围；不静默修复、不用摘要覆盖原始证据。

sci-result-auditor
阶段化写作

从初稿到修订与校样

先确定稿件阶段，再在已核验证据和当前主线内写作；改写文字不等于晋升结论。

academic-manuscript-writing

还包括 论文配套清单与 资产维护审查。查看 完整架构与职责边界。

需要多深，就进入多深

这是不同任务的处理强度，不是每次都要走完的流水线。以下为 main 的当前工作方式；保留关键论文阅读、统计标准和有效负结果。

讨论回答眼前问题，不自动建档、下载或远端执行。
定向查新核验最近先例，说明实质重合和可检验差别。
最小探索在授权范围内，用固定的小协议区分竞争解释。
正式实验完整协议、原始证据、验证与实验记录闭环。
投稿审计对冻结材料做完整一致性检查，不自动提交。

复用未变上下文，按事件更新记录。尚未通过可比真实任务量化 token 或额度节省。
